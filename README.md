# multi-tasking
Code for Beiran, Marschall, Zemlianova, Di Bernardo, Ostojic & Litwin-Kumar.: Neural circuit mechanisms for multi-tasking.

Simulations and figures that implement forms of multi-tasking.

`compare_mechanisms.py` implements transient task selection, selection via connectivity modulation, and via barcodes. Generates three-dimensional projections of neural activity trajectories.

`fig_*.py` generates figure panels as shown in the manuscript.

`utils.py` contains utilities for generation of low-rank connectivity components and recurrent neural network simulations.
